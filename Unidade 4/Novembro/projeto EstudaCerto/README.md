# EstudaCerto

Chatbot de estudos de Ciência da Computação, feito em HTML, CSS e JavaScript puro (sem API e sem internet).

## Como usar
Abra o `index.html` no navegador, ou publique pelo GitHub Pages.

## Como mudar o tema
Edite a lista `BASE` dentro do `<script>` do `index.html`: cada item tem um título, as palavras-chave e a resposta.
